# ADR-005：Agent 能力由运行时探测决定，未知能力按不支持处理

- 状态：accepted for M1/M3
- 日期：2026-10-24
- 相关任务：CODO-003、CODO-101、CODO-102

## 背景

本机四家 CLI 版本和帮助输出不同。帮助只能证明参数存在，不能证明认证、取消、审批或跨版本恢复真的可用。

## 决定

Registry 记录路径、版本、认证状态和诊断；Adapter 为每个 Profile 返回能力集合。`unknown` 不升级成 true；不能安全支持时显示 PTY fallback 和原因。危险免审批参数不由 Codovo 默认注入。

## 后果

UI 可以按能力禁用不安全按钮；版本升级后要重新探测。CODO-002 的矩阵作为版本兼容测试输入，不作为永久承诺。
