---
description: "在 Gitee 上新建一条 issue（提交前先确认标题与正文）"
allowed-tools: Bash
---

从用户随命令给出的文字里提取**标题**（必需）和**正文**（可选，可多行 markdown）。

- 标题为空就别猜、别用正文硬凑——先问用户要一句标题。
- 正文没给可以只发标题（`-b` 省略），不用追问。

**提交前先把「标题 + 正文」原样给用户确认一次**，确认后再往下跑；用户明确说「直接建 / 不用确认」才跳过。

用 Bash 工具跑（**不传 `-R`**，仓库跟着当前目录的 git remote 推断）：

```bash
gitee issue create -t "<标题>" -b "<正文>" -j
```

然后：

- 标题/正文里可能含引号或特殊字符，用单引号或把内容塞进变量再传，别让 shell 吃掉字符。
- 从返回的 JSON 取 `number` / `html_url` 报告给用户——新建了哪条、链接是什么。
- 命令失败（没装 / 没登录 / 缺 scope / 不在 git 仓库 / 网络）**原样贴出错误**，不要自己编内容，也不要退回网页操作。
- 只做新建：不改标签、指派、状态等任何其它内容，除非用户在这条命令里明确要求并确认。
